おかね帳（自分専用のお金管理アプリ）
==================================================

■ このフォルダについて
  iPhone のホーム画面から使う Web アプリ（PWA）一式です。
  データは iPhone の中だけに保存され、外部には送信されません。

■ iPhone で使い始めるまで（無料の GitHub Pages を使う場合）

  【パソコンで】
  1. https://github.com にアクセスし、無料アカウントを作成する
  2. 右上の「＋」→「New repository」
       ・Repository name：okane（好きな名前でよい）
       ・Public を選ぶ（無料で公開ページを作るため。公開されるのはアプリの
         プログラムだけで、あなたの家計データは含まれません）
       ・「Create repository」を押す
  3. 表示された画面の「uploading an existing file」をクリック
  4. このフォルダ（okane-cho）の「中身」をすべて選んで、ブラウザにドラッグ＆ドロップ
       ※ フォルダごとではなく、index.html などが一番上に来るようにする
  5. 下の「Commit changes」を押す（アップロード完了まで数十秒待つ）
  6. 上のメニュー「Settings」→ 左の「Pages」
       ・Source：Deploy from a branch
       ・Branch：main ／ /(root) を選んで「Save」
  7. 1〜2分待つと、同じ画面の上部に
       https://（ユーザー名）.github.io/okane/
     のようなアドレスが表示される

  【iPhone で】
  8. Safari で上のアドレスを開く
  9. 画面下の共有ボタン（□に↑）→「ホーム画面に追加」→「追加」
 10. ホーム画面の「おかね帳」アイコンから起動する
       ※ 以後は必ずこのアイコンから使ってください。
         Safari のタブで開いたものとは、データの保存場所が別になります。
 11. 「通帳・現金」タブ →「＋ 追加」で、通帳や財布と今の残高を登録する
 12. レシート読み取りは、初回だけ Wi-Fi などオンラインで1回使ってください
     （読み取り用データ約10MBを読み込み、以後はオフラインでも使えます）

■ バックアップ（必ず定期的に）
  「通帳・現金」タブの下「バックアップを書き出す」→ 共有メニューで
  「"ファイル"に保存」→ iCloud Drive などに保存。
  復元は「バックアップから復元」で、保存したファイルを選びます。
  ・ホーム画面のアイコンを削除すると、データも消えます
  ・機種変更時は、古い iPhone で書き出し → 新しい iPhone で復元
  ・「レシート画像も含める」を外すと軽くなりますが、画像は戻りません

■ アプリを更新するとき
  新しいファイルを GitHub の同じ場所にアップロードし直すと、
  次にアプリを開いたとき（オンライン時）に新しい版になります。データは消えません。

■ 中身
  index.html / manifest.webmanifest / sw.js … アプリの入口・設定・オフライン対応
  css/ js/ icons/                            … 画面・処理・アイコン
  vendor/                                    … 端末内文字認識（Tesseract.js）一式
